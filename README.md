## 🚀 Featured Projects

### [Mokoji](https://github.com/osama-Yosef/steam-gallery-app)
A steam iron store and repair service built on top of a full back office, with three roles in one app: customer, technician and admin.
- Store, cart and checkout; repair requests with a live queue; warehouse, cashbox and reports for the admin
- Access controlled with Supabase Row Level Security; push notifications through FCM

`Flutter` `Supabase` `PostgreSQL` `Riverpod` `go_router`
· Public website: [Next.js + Cloudflare Workers](https://github.com/osama-Yosef/-Release)

### [Al-Fardos Factory](https://github.com/osama-Yosef/app_alfardos)
The order management system of a metal processing factory, in daily use. Four interfaces in one app: client, engineer, office and floor worker.
- Full order lifecycle, from the client's request to engineering review, pricing and production
- Live data across roles, file uploads and push notifications

`Flutter` `Firebase` `BLoC / Cubit` `FCM` `Cloudinary`

### [Al-Fardos Management](https://github.com/osama-Yosef/Alfardos-Management)
Arabic accounting and business management for small businesses: invoices, customers, suppliers, cashboxes, stock and reports.
- Every operation is a balanced double-entry posting written in one atomic Firestore transaction
- Idempotent posting (no duplicates on retry), PDF invoices, tests for the ledger and security rules

`Flutter` `Firebase` `Riverpod` `Windows` `Android`

### [Length Factory](https://github.com/osama-Yosef/length-factory)
Order and inventory management for a manufacturing business, with admin, customer and worker roles.
- Clean Architecture (`data` / `domain` / `presentation`) with Cubit, `get_it` and `Either`-based error handling
- Role-based access: workers see only the production queue, never prices; PDF invoices

`Flutter` `Firebase` `Cubit` `Clean Architecture`

**Also:** [Eyan](https://github.com/osama-Yosef/Eyan) (doctor booking, Arabic/English) · [Smart Institute](https://github.com/osama-Yosef/Smart_Institute_App) (student and doctor portal) · [Taskati](https://github.com/osama-Yosef/taskaty-app) (to-do app)
